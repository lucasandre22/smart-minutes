# [Backend review]: Maintainability, configuration, and test gaps

## Scope and baseline

Track findings **F061-F074** from the Python backend review at [`c4808c01d8b08b800fbddcc02547afb2701554eb`](https://github.com/lucasandre22/smart-minutes/commit/c4808c01d8b08b800fbddcc02547afb2701554eb).

Evidence is static inspection of imports, interfaces, configuration, tests, dependencies, and benchmarks. All 49 Python files passed syntax parsing. Test collection was attempted but the available Python 3.13.5 interpreter had no pytest installed. No dependency installation, model downloads, inference benchmarks, or full environment compatibility checks were performed. Dependency findings are declaration/layout gaps, not claims of known vulnerabilities.

## Findings

- [ ] **F061 - Imports use incompatible package roots.** Production/experimental code mixes `llms.*`, `backend.llms.*`, and nonexistent `src.*`. Action-item refine and map-reduce are affected. Define one package layout and supported entry points, then verify imports from a clean environment. [Action-item source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/action_items/refine.py#L5); [map-reduce source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/summarization/map_reduce.py#L5).
- [ ] **F062 - Duplicate `invoke()` definitions silently replace methods.** Summarization, Minutes, ActionItems, and CustomRequest each define `invoke()` twice. These are not Python overloads; only the second definition survives. Consolidate input contracts and type hints, with explicit normalization if both strings and documents are supported. [Representative source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/summarization/summarization.py#L52).
- [ ] **F063 - Ollama wrapper loses outputs and keeps stale prompt chains.** `invoke()` does not return its result and sends a kwargs dictionary to the model. `set_prompt()` does not invalidate an existing chain. Define consistent invocation behavior and rebuild/invalidate chains after prompt changes. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/llms/ollama/ollama_llm.py#L43).
- [ ] **F064 - Follow-up helpers call incompatible interfaces.** Action-item and minutes helpers pass arguments to zero-argument prompt factories and conflict with the wrapper's keyword-only `invoke()` interface. Repair or remove these unused/broken paths and verify the retained public interfaces. [Action-item source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/action_items/refine.py#L68); [minutes source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/minutes/refine.py#L62).
- [ ] **F065 - Duplicate minutes implementation contains unary-plus string statements.** A module-level copy splits concatenation across separate statements, leaving unary `+` applied to strings in the citation loop. It parses but fails when executed. Keep one tested implementation and remove obsolete copies. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/minutes_service.py#L165).
- [ ] **F066 - Index update/save helper omits the destination.** `update_and_save_db()` calls FAISS `save_local()` without its required folder path. Make helper contracts consistent and verify save/reload behavior. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/rag/database/docs_rag_database.py#L26).
- [ ] **F067 - Configuration overwrites environment values and depends on CWD.** Import replaces deployment-supplied addresses/paths and creates relative directories. Use validated overridable defaults and stable resolved paths, with explicit initialization. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/core/config.py#L3).
- [ ] **F068 - Imports trigger heavyweight initialization and side effects.** Class definition loads the embedding model, configuration creates directories, and another module loads a database on import. Move resource creation into an explicit application lifecycle with observable failures and isolated test substitutes. [Embedding source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/rag/database/local_rag_database.py#L6); [database source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/core/vector_database.py#L4).
- [ ] **F069 - Progress is an uncalibrated fixed countdown.** Each chunk is assumed to take 21 seconds regardless of model/hardware/workload; updates stop when the estimate expires even if inference continues. Prefer completed-step progress and clearly labeled calibrated estimates. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L47).
- [ ] **F070 - Task mutation and SSE observation have weak contracts.** Updating with no task can fail; SSE compares object identity and can miss in-place mutation. Streams lack explicit heartbeats and resumable event IDs. Define immutable/versioned job snapshots, absent-task behavior, and supported reconnect semantics. [Task source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/task/task_manager.py#L22); [stream source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L65).
- [ ] **F071 - Tests provide little automated regression protection.** `test_evalluation.py` imports absent `src.*`, has no pytest test functions, and runs its experiment only under `__main__`. Other experiments depend on local files or load models on import. Add isolated coverage for API validation, path boundaries, jobs, parsing, indexes, and chain wiring; keep model experiments separate. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/tests/test_evalluation.py#L4).
- [ ] **F072 - Benchmarks are not repeatable or failure-safe.** NVML initializes on import; zero samples divide by zero; the stop event is never reset; `stop_statistics(x)` has an incompatible signature. The Ollama benchmark lacks failure-safe worker cleanup. Define supported hardware behavior, restartable sampling, and cleanup in failure paths. [Hardware source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/benchmarks/hardware_statistics.py#L9); [benchmark source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/benchmarks/benchmark_llm_ollama.py#L27).
- [ ] **F073 - Dependency declarations mix runtime and experiments.** Requirements include an unconditional Windows-specific package while benchmark imports (`psutil`, `pynvml`, `matplotlib`) are not explicitly declared. Separate runtime/evaluation/benchmark dependencies and use platform markers where appropriate; verify clean installation on supported platforms/Python versions. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/requirements.txt).
- [ ] **F074 - Jobs lack structured observability and reproducibility metadata.** Model settings, prompt version, input hash, duration, evaluation results, and failure details are not retained with artifacts. Console prints lack consistent job correlation. Persist effective job metadata and structured sanitized logs. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/task/task.py#L3).
