# [Backend review]: Generation behavior and output quality

## Scope and baseline

Track findings **F021-F034** from the Python backend review at [`c4808c01d8b08b800fbddcc02547afb2701554eb`](https://github.com/lucasandre22/smart-minutes/commit/c4808c01d8b08b800fbddcc02547afb2701554eb).

Evidence: static inspection plus isolated probes reproducing empty-input division by zero and brace interpolation failures. Model quality, prompt-injection behavior, and PDF Unicode failures were not exercised end to end. All 49 Python files parsed; full tests were unavailable because the review interpreter had no pytest installed. Quality concerns require representative sanitized inputs and recorded model settings.

## Findings

- [ ] **F021 - Requested chunk size is ignored.** All four generation methods replace the request value with `1024`. Honor a validated size or remove the ineffective setting from the contract. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L177).
- [ ] **F022 - Output language is ignored.** Language parameters are accepted but never passed into generation prompts/chains. Apply supported language choices consistently or reject unsupported values explicitly. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L171).
- [ ] **F023 - Summary evaluation switch is ignored.** `enable_evalluation_system` does not control any evaluation. Implement the requested evaluation and expose its result/failure state, or explicitly declare it unavailable. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L171).
- [ ] **F024 - Action-item participants are ignored.** The accepted participant data never reaches extraction. Pass it through a defined ownership-resolution contract and handle unknown owners without inventing assignments. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L293).
- [ ] **F025 - Settings are inconsistently named and applied.** `top_p` and `debug_traces` are stored but unused; generation hardcodes `verbose=True`. Reads return snake_case keys while writes require `topP`/`debugTraces`. Establish one schema and pass effective settings into generation. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L151).
- [ ] **F026 - Minutes use stale and hardcoded models.** A class-level LLM captures configuration on import; citation context uses a separate hardcoded Llama model. Create models from the job's validated configuration, declare any auxiliary-model requirement, and preserve reproducibility. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/minutes_service.py#L26).
- [ ] **F027 - Braces in user input become prompt-template fields.** Custom requests and participant strings are concatenated before template parsing. JSON such as `{"answer": "text"}` can trigger missing-variable errors. Bind user content as values rather than template source. [Custom request source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/custom_request/template_refine.py#L7); [minutes source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/minutes/template_refine.py#L34).
- [ ] **F028 - Empty transcript chunking divides by zero.** Zero tokens produce zero chunks and a subsequent `divmod(..., 0)`. Define and validate empty/whitespace input behavior before generation. Reproduced with an isolated function probe. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/utils.py#L29).
- [ ] **F029 - Token-sized chunks do not enforce token limits.** The implementation estimates a count using tokens, then splits by characters; individual chunks can exceed the requested budget. Its tokenizer is also independent of the selected model. Use an explicit, tested token-budget strategy. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/utils.py#L19).
- [ ] **F030 - Chunk boundaries can sever meeting context.** Transcript chunks split arbitrary characters without overlap or speaker boundaries; PDF chunks use `separators=[]`. Preserve turns/paragraphs and use controlled overlap so owners, negations, and decisions remain interpretable. Measure effects with representative fixtures. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/utils.py#L31).
- [ ] **F031 - Refinement lacks a full context-window budget.** Instructions, accumulated answer, next chunk, and output reserve are not budgeted together. Long meetings can overflow or truncate context. Bound each complete request and define behavior when accumulated content grows. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/summarization/refine.py#L45).
- [ ] **F032 - Output structure and factuality guarantees are weak.** Active summaries are generic prose, action-item prompts focus on commissions, and owners/deadlines/decisions/evidence have no enforced schema. Evaluate omissions, invented assignments, later corrections, and individual tasks; define structured outputs where useful. [Summary prompt](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/summarization/template_refine.py#L20); [action-item prompt](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/action_items/template_refine.py#L40).
- [ ] **F033 - Source content lacks an explicit instruction trust boundary.** Transcripts and retrieved documents enter instruction-style prompts without explicit handling as untrusted data or output validation. Evaluate embedded-instruction cases and add suitable data boundaries and result checks. This is a quality/security risk, not a demonstrated exploit. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/custom_request/template_refine.py#L9).
- [ ] **F034 - PDF output lacks general Unicode support.** The pinned FPDF implementation uses a core Arial font without registering a Unicode font. Smart punctuation, emoji, and other model output can fail serialization. Register supported fonts and define fallback behavior with representative Unicode fixtures. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/pdf_service.py#L11).
