# [Backend review]: Parsing and evaluation defects

## Scope and baseline

Track findings **F048-F060** from the Python backend review at [`c4808c01d8b08b800fbddcc02547afb2701554eb`](https://github.com/lucasandre22/smart-minutes/commit/c4808c01d8b08b800fbddcc02547afb2701554eb).

Evidence: static inspection and isolated AST-extracted probes reproduced multiline SRT data loss, the missing async claim argument, a `None` async-wrapper result, an uninitialized metric error attribute, and invalid JSON exception construction. These probes did not load model dependencies. All 49 Python files parsed; full tests were unavailable because the review interpreter had no pytest installed. Full model-backed evaluation remains unverified.

## Findings

- [ ] **F048 - SRT parsing loses multiline text and misreads numeric dialogue.** Each content line overwrites the previous one, and any numeric line becomes a chapter index. Parse complete subtitle blocks, preserve all content lines, and support valid timestamp variants with clear invalid-input errors. The multiline loss was reproduced. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/scripts/srt_file_parser.py#L6).
- [ ] **F049 - VTT cleaning can remove meaningful content and attribution.** Heuristic deduplication and parenthesized speaker detection flatten cues and remove timings; uppercase `.VTT` also bypasses cleaning in the upload path. Preserve structured cues, normalize extensions, and test genuine repetition, speaker changes, and overlapping captions. [Cleaner source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/scripts/vvt_cleaner.py#L12); [upload source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/api/services/service.py#L130).
- [ ] **F050 - Transcript preprocessing logs full meeting contents.** The cleaner prints the complete transcript regardless of debug settings. Log controlled metadata and sanitized errors instead; verify ordinary operation does not emit transcript text. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/scripts/vvt_cleaner.py#L28).
- [ ] **F051 - Default async evaluation omits a required argument.** `_a_generate_claims()` calls `generate_claims(text=text)` without `maximum_claims`, so the default async path raises `TypeError`. Supply the configured budget consistently. Reproduced with an isolated probe. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/meeting_summarization_metric.py#L421).
- [ ] **F052 - Async `measure()` discards the score and elapsed time.** It runs `a_measure()` without returning the result and omits async-path duration accounting. Return a consistent float and set timing/state in both modes. The `None` return was reproduced with a stubbed async measurement. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/meeting_summarization_metric.py#L81).
- [ ] **F053 - Async model generation blocks the event loop.** `a_generate()` directly calls synchronous generation, so surrounding `asyncio.gather()` does not yield genuine concurrent model calls. Use an async model API or an appropriate bounded offload strategy. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/ollama_eval_model.py#L21).
- [ ] **F054 - Metric success checking reads an uninitialized attribute.** `self.error` is accessed before the method's exception handler but never initialized. Define measurement state and pre-measurement/failure behavior. The `AttributeError` was reproduced. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/meeting_summarization_metric.py#L444).
- [ ] **F055 - Sync and async metrics have different semantics.** Sync mode extracts per-chapter claims/questions and assumes original support; async mode handles a list as a whole and explicitly checks original answers. Define one input normalization and scoring contract and verify equivalent deterministic responses yield equivalent scores. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/meeting_summarization_metric.py#L90).
- [ ] **F056 - Reused metrics retain questions from previous inputs.** Generated questions become instance state and are reused on later measurements. Distinguish caller-supplied questions from per-input generated questions and reset transient state for every measurement. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/meeting_summarization_metric.py#L348).
- [ ] **F057 - Evaluation budgets and model-response validation are incomplete.** Empty lists divide by zero; many chapters can receive zero claims. Verdict strings are unrestricted, alignment counts are unchecked, and answer counts are not consistently validated against actual questions. Validate inputs, budgets, response schemas, cardinalities, and supported verdict values before scoring. [Budget source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/meeting_summarization_metric.py#L91); [verdict source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/meeting_summarization_metric.py#L403).
- [ ] **F058 - Evaluation prompts demonstrate invalid JSON.** Alignment examples have broken quoting/punctuation and trailing commas despite requiring strict JSON. Make examples parseable and consistent with the response schema; verify examples automatically where useful. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/evalluation/summarization/template.py#L76).
- [ ] **F059 - Document summarization has independent integration blockers.** It imports absent `rag.template`, uses global `document_loader` instead of `self.loader`, and its example omits required chunk size. The initial prompt asks for prose although output is parsed as JSON. Repair imports, instance usage, example invocation, and the structured-output contract. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/rag/document_summarizer.py#L7).
- [ ] **F060 - JSON extraction mishandles strings, candidates, and errors.** Brace counting ignores quoted strings; the first malformed candidate stops parsing. `JSONDecodeError` is constructed without `doc` and `pos`, causing a different `TypeError` on missing or invalid JSON. Use a robust decoder/structured parser and preserve meaningful exceptions. Both error branches were reproduced. [Source](https://github.com/lucasandre22/smart-minutes/blob/c4808c01d8b08b800fbddcc02547afb2701554eb/backend/rag/document_summarizer.py#L45).
